# קשר — Everbox

מערכת פשוטה לבקשות מכירות וטיפול של Web 3D. עברית, מותאמת לנייד, בחירת שם ללא הרשמה.

## הפעלה ב־Vercel
1. חברו את הריפו לפרויקט Vercel, Framework: Next.js, Root Directory: שורש הריפו.
2. צרו פרויקט Supabase והפעילו ב־SQL Editor את `supabase/setup.sql`. הוא יוצר את טבלת הבקשות ואת אחסון התמונות.
3. ב־Vercel → Settings → Environment Variables הוסיפו `SUPABASE_URL` ו־`SUPABASE_SECRET_KEY` מתוך פרויקט Supabase. אפשר להשתמש ב־`SUPABASE_SERVICE_ROLE_KEY` במקום מפתח secret. המפתח נשאר בשרת בלבד; אין להכניס אותו לקוד או לשיחה.
4. הפעילו Redeploy לפריסה האחרונה.

ללא ההגדרות האלה בחירת השם עובדת, אך שמירת בקשות ותמונות אינה זמינה.

## שימוש
בוחרים יצחק, יוסף חיים, דניאל, יואל, אביעד או Web 3D. אנשי המכירות רואים את בקשותיהם; יואל, אביעד ו־Web 3D רואים הכול ומעדכנים סטטוס ותאריך יעד. אפשר לצרף עד שלוש תמונות לכל בקשה או עדכון, כולל צילום מהטלפון. בקשות שעברו את תאריך היעד מופיעות בראש הרשימה.

בחירת שם היא בחירת תצוגה, ללא אימות זהות: כל מי שמחזיק בקישור יכול לבחור כל שם, בהתאם לאופן העבודה שהוגדר.

## פיתוח
Node.js 22.13 ומעלה. `npm ci`, לאחר מכן `npm run dev`. להגדרות מקומיות העתיקו `.env.example` אל `.env.local`. בדיקות: `npm test`; בניית production: `npm run build`.

הבדיקות מחליפות את שירות האחסון בתשובות HTTP מבוקרות. יש לבדוק שמירת בקשה ותמונות בין שני מכשירים לאחר חיבור Supabase.
