# קשר — Everbox

מערכת פשוטה לבקשות מכירות וטיפול של Web 3D. עברית, מותאמת לנייד, בחירת שם ללא הרשמה.

## הפעלה ב־Vercel

1. חברו את הריפו לפרויקט Vercel כפרויקט Next.js.
2. בפרויקט פתחו Storage, צרו Vercel Blob Store וחברו אותו לסביבות Production ו־Preview.
3. בצעו Redeploy. Vercel מוסיפה אוטומטית את משתני האחסון הדרושים.

Vercel Blob שומר גם את הבקשות והעדכונים כ־JSON וגם את התמונות. לא נדרש מסד נתונים חיצוני.

אנשי המכירות רואים את בקשותיהם; יואל, אביעד ו־Web 3D רואים הכול ומעדכנים סטטוס ותאריך יעד. אפשר לצרף עד שלוש תמונות לכל בקשה או עדכון, כולל צילום מהטלפון.

בחירת שם היא בחירת תצוגה ללא אימות זהות: כל מי שמחזיק בקישור יכול לבחור כל שם, בהתאם לאופן העבודה שהוגדר.
